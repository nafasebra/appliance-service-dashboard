# داشبورد شرکت خدمات تعمیرات لوازم خانگی

اسکلت اولیه با React، TypeScript، Vite و Tailwind CSS. زبان صفحه فارسی و جهت آن راست‌به‌چپ است.

## اجرا

نیازمند Node.js نسخهٔ 20.19 به بالا در شاخهٔ 20، یا 22.12 به بالا است.

```sh
npm install
npm run dev
```

## بررسی و ساخت

```sh
npm run typecheck
npm run build
npm run preview
```

## ساختار

- `src/app/`: نقطهٔ شروع رابط کاربری
- `src/components/ui/`: کامپوننت‌های محلی shadcn/ui
- `src/styles/`: استایل‌های عمومی و Tailwind
- `docs/project-context.md`: زمینهٔ کسب‌وکار و محدودهٔ توافق‌شده
- `AGENTS.md`: دستورالعمل‌های کدنویسی، معماری، طراحی سیستم و سناریوی کسب‌وکار

## قالب‌بندی کد

```sh
npm run format
npm run format:check
```

Prettier قالب‌بندی فایل‌های پروژه را یکسان می‌کند. فایل‌ها با UTF-8، پایان خط LF، تورفتگی دو فاصله و یک خط جدید در انتهای فایل ذخیره می‌شوند. تنظیمات Git و EditorConfig نیز با همین قواعد هماهنگ‌اند.

مسیر `@/` به `src/` اشاره می‌کند. کامپوننت‌های shadcn/ui داخل خود پروژه نگهداری می‌شوند و تنظیمات مسیر و تم آن‌ها در `components.json` قرار دارد. برای استفاده، کامپوننت موردنیاز را از `@/components/ui/...` وارد کنید.

## مسیریابی

مسیریابی با TanStack Router و تعریف مسیرها در کد انجام می‌شود:

- `src/app/router.ts`: ساخت درخت مسیرها و ثبت نوع روتر
- `src/app/routes/root-route.tsx`: چیدمان مشترک و صفحهٔ مسیر نامعتبر
- `src/app/routes/index-route.tsx`: صفحهٔ اصلی در `/`

برای افزودن صفحه، با `createRoute` یک مسیر تعریف و آن را به فرزندان ریشه در `router.ts` اضافه کنید. برای لینک‌های داخلی از `Link` در `@tanstack/react-router` استفاده کنید.

در استقرار نهایی، میزبان باید درخواست مسیرهای برنامه را به `index.html` بازنویسی کند تا بازکردن مستقیم و تازه‌سازی صفحات کار کند.
